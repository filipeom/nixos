## Objective

This runbook describes how to expose a new HTTP site using a subdomain.
Sites running in `anchor-01` all listen on port 443. In order to add
additional HTTP site it must be added to the current nginx reverse proxy config.

## Prerequisites & Safety Checks

- N.A.

## Procedure

You can see the available sites in `/etc/nginx/sites-available/`. To add a new
site you need to create another `/etc/nginx/sites-available/SERVER_NAME.conf`
file and then enable it with:

```sh
sudo ln -s /etc/nginx/sites-available/SERVER_NAME.conf /etc/nginx/sites-enabled/
```

And then reload:

```sh
sudo systemctl reload nginx
```

### Generate new certificates

We use letsencrypt and certbot to manage our certificates.

```sh
sudo certbot --nginx -d SERVER_NAME
```
