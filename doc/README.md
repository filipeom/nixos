# Documentation and Function Specs

Here we document important architectural decisions or functional specs for my homelab.

The files in this directory adhere to the following convention: `[TYPE]-[ID]_[short-title].md`. Where:

- `TYPE`: Identifies document type, e.g:
    - ADR: Architecture Decision Record
    - RUN: Runbook
    - FS: Functional Specification
- `ID`: Unique sequence number.
- `short-title`: Concise description of the documents subject.
