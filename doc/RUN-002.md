## Procedure

I use `ddclient` to fetch the ip of the machine and update it in OVH.
In `anchor-01.local` the configuration is in `/etc/ddclient/ddclient.conf`.
To obtain the addresses we use two programs:

- ipv4: `/usr/local/bin/external-ip`
- ipv6: `/usr/local/bin/get-ip`

I'm running a systemctl service: `sudo systemctl status ddclient.service`.

To restart the service you can do:

```sh
$ sudo systemctl stop ddclient
$ sudo rm /var/cache/ddclient/ddclient.cache
$ sudo systemctl restart ddclient
```
