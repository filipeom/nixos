## Purpose

Living inventory of physical infrastructure: hosts, storage, rack space, power,
and network hardware. This document records **what exists now** and changes as
hardware changes; architectural *decisions* live in [ADR-001](ADR-001.md).

A new `INV-` document is only created for a *different subject* (e.g.
`INV-002` network addressing, `INV-003` services). Updates to the same subject
edit this file in place.

**Scope:** rack and always-on homelab hosts (`anchor-01`, `vessel-02`,
`vessel-01`), the network hardware, and the UPS. Personal laptops (`helm`) and
work machines (`cflinux`) are out of scope.

### Notes

- `anchor-01` also has an **NVIDIA GTX 1660 Super** (NVIDIA open kernel driver;
  Plex transcoding / GPU workloads).
- `vessel-01` also has an **NVIDIA GTX 1660 Super** (Ollama CUDA workloads).
- `anchor-01` is the oldest host (i7-7700, 2017) and the primary data holder.
- `vessel-01` and `vessel-02` each have a 32 GiB swapfile configured for
  hibernation/zswap. `vessel-01` hibernates, so it is a best-effort edge node
  (see [ADR-001](ADR-001.md)).
- `anchor-01` data lives on three single-disk ZFS pools: `zpool` → `/mnt/hdd`
  (WD40EFPX 4TB; Nextcloud data), `mediapool` → `/mnt/hdd0` (WD161KFGX 16TB;
  Plex media), `cachepool` → `/mnt/hdd1` (Hitachi 1TB; Plex + user data). No
  child datasets, no encryption. All pools are ONLINE; `cachepool` is 91% full.
- `anchor-01` runs NixOS 26.05 since the [FS-001](FS-001.md) migration
  (2026-10): native Plex, Nextcloud 34 (MariaDB + Redis), nginx on `:80`
  (internal), and Podman. The Ubuntu snaps and the Docker monitoring stack are
  gone. NUT and native Prometheus/Grafana are **not yet re-configured**
  ([FS-001](FS-001.md) Phase 4).
- `vessel-02` runs the active edge (nginx + ACME DNS-01, `ddclient`, unbound
  DNS, WireGuard server) plus compute (GitHub runner, Minecraft BMC4). See
  Network Hardware.
- `vessel-01` runs a Hyprland desktop stack and Ollama (CUDA).
- Infrastructure hosts use static addresses in the `192.168.1.100–199`
  reservation: `anchor-01` `.124`, `vessel-01` `.110`, `vessel-02` `.111`
  ([ADR-001](ADR-001.md#addressing-plan)).
