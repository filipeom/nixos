## Purpose

Living inventory of physical infrastructure: hosts, storage, rack space, power,
and network hardware. This document records **what exists now** and changes as
hardware changes; architectural *decisions* live in [ADR-001](ADR-001.md).

A new `INV-` document is only created for a *different subject* (e.g.
`INV-002` network addressing, `INV-003` services). Updates to the same subject
edit this file in place.

**Scope:** rack and always-on homelab hosts (`anchor-01`, `vessel-02`,
`vessel-01`), the network hardware, and the UPS. Personal laptops (`helm`) and
work machines are out of scope.
